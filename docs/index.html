На основе Happwner от Omegaplex и slavrom21 — с доработками для повседневного использования.

01 / DEVICE

Выберите устройство

Android, Android TV, iOS, Windows, macOS и Linux. Профиль задаёт заголовки запроса и платформу в стандартном User-Agent Happ.

02 / EXPORT

Сохраните в файл

Полный обработанный результат в UTF-8, а не обрезанный текст предпросмотра. Выбирайте папку через системный диалог Android.

Большие подписки — частями

04 / RELIABILITY

Ошибка — не подписка

HTTP 500 с JSON отображается как ошибка. Bridge сохраняет ошибочный статус, вместо того чтобы выдавать его за успешную подписку.

БЫСТРЫЙ СТАРТ

От ссылки до файла.

  1. Установите APK

    Скачайте файл из Releases. Для основных функций root и Xposed не нужны.

  2. Настройте запрос

    Вставьте ссылку. Выберите устройство, User-Agent и при необходимости свой HWID.

  3. Получите результат

    Нажмите «Получить прокси», затем значок сохранения рядом с результатом.

Уже установлен оригинальный Happwner?

Подпись этого форка другая. Установить его поверх оригинала нельзя: сначала сохраните нужные данные и удалите оригинал. Идентификатор пакета сохранён для совместимости Xposed. Последующие релизы этого форка используют постоянный собственный ключ.
