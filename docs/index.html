Профиль запроса

Выберите, каким
устройством представиться.

Откройте «Запрос от», выберите платформу, модель и клиент. Версию ОС и User-Agent можно отредактировать вручную.

HWID создаётся отдельной кнопкой и сохраняется для выбранного пресета. При следующем запросе он останется прежним.

Нужны root или Xposed?

Для расшифровки ссылок crypt–crypt5, настройки запроса и экспорта root и Xposed не нужны. Xposed требуется для перехвата ссылок и изменения поведения внутри Happ или других целевых приложений.

Инструкция по Xposed
Какие клиенты есть в профиле запроса?

Happ, v2RayTun, INCY, v2rayNG, Hiddify, sing-box и mihomo. Для поддерживаемых Android-приложений, установленных на устройстве, версия берётся из самого приложения. User-Agent также можно вписать вручную.

Встроенные версии обновлены 5 ноября 2026 года. Это набор пресетов, а не обещание совместимости с каждым провайдером.

Где посмотреть исходники и проверки?

Код и история изменений доступны на GitHub. GitHub Actions запускает тесты профилей, HWID, HTTP-ошибок и больших JSON. Диалог выбора проверяется на API 28 и 35 через Robolectric.

Проверка на реальном телефоне пока не проводилась. Автотесты её не заменяют.
