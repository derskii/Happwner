# Happwner 1.4.0 · derskii

Некоммерческий форк [Omegaplexx/Happwner](https://github.com/Omegaplexx/Happwner). Авторы оригинала — **Omegaplex и slavrom21**.

## Новое

- Мастер запроса: платформа → модель устройства → версия ОС → клиент. Пресеты Google Pixel 7/8/9, Galaxy S24/S25, iPhone 11–16, iPad, MacBook, Windows 10/11, Linux и Android TV; модель и версия ОС редактируются. Полный профиль передаётся в Bridge-ссылке.
- Генератор синтетического HWID с форматами Android/TV (16 hex), Apple/Windows (UUID), Linux (32 hex). Генерация только по кнопке; применённое значение сохраняется для каждого пресета. Замена существующего ID требует подтверждения.
- Экспорт полного обработанного результата в UTF-8 `.json` или `.txt` через системный диалог Android, без разрешения на доступ ко всем файлам.
- Обновлены User-Agent Happ и INCY; добавлены v2rayNG, Hiddify, sing-box и mihomo. Для поддерживаемых установленных клиентов используется их версия; ручной ввод сохранён.
- Конвертация и расшифровка вынесены с главного потока. Просмотр больших результатов — страницами по 15 000 символов, без обрезания экспортируемого содержимого.

## Исправления

- Многострочные JSON-массивы теперь обрабатываются целиком, а не построчно.
- HTTP 500 с JSON не передаётся в конвертер как подписка. Bridge возвращает ошибочный статус вместо HTTP 200.
- Защита от слишком глубокого JSON, чрезмерно больших ответов и переполнения буфера обмена.
- Очистка результата отменяет активную задачу и исключает появление устаревшего ответа.
- Оба пути создания Bridge-ссылки учитывают устройство; импорт корректно декодирует `+` в URL-параметрах.
- Bridge слушает только `127.0.0.1`, а не все сетевые интерфейсы; подписочная ссылка больше не пишется в лог запроса.
- Исправлены векторные пути иконок, которые могли вызывать падения на старых устройствах. Monet-ресурсы вынесены в API 31+, плитка Quick Settings отключена на API ниже 24.
- Ожидающий экспорт переживает пересоздание Activity без сохранения большой подписки в Bundle.

## Установка

Скачайте APK ниже. Android 5.0+. Подпись проверяется перед публикацией, SHA-256 — в `SHA256SUMS.txt`, сертификат — в `SIGNATURE.txt`.

**Подпись отличается от оригинала.** Для перехода с оригинального Happwner сохраните нужные данные и удалите оригинал перед установкой. Обновления этого форка подписываются одним постоянным ключом. Идентификатор пакета `com.happwner` сохранён для совместимости Xposed.

Профили меняют только метаданные запроса, а не физическое устройство. Совместимость зависит от провайдера. Автотесты включают 500/1000 JSON-конфигов, HTTP 500, ограничение ответа и выбор платформ; ручная проверка на реальном телефоне в этот релиз не включена.

Страница проекта: https://derskii.github.io/Happwner/

Условия оригинала сохранены: **только некоммерческое использование**, с указанием авторов и ссылкой на исходный репозиторий.
